# How to put this on GitHub (about 10 minutes)

## 1. Create the repository
1. Go to github.com and sign in. If you do not have an account, create one with your school email.
2. Click the **+** in the top right, then **New repository**.
3. Name it: `data5500-school-threat-trends`
4. Description: `Senior design project: classifying and comparing viral school-threat trends in news coverage, 2016-2026`
5. Choose **Public** so your professor can open it without an invitation.
6. Do **not** check "Add a README file". This folder already has one.
7. Click **Create repository**.

## 2. Upload these files
1. On the new empty repository page, click **uploading an existing file**.
2. Drag the whole unzipped folder contents into the browser window. GitHub keeps the folders.
3. In the box at the bottom write: `Initial commit: queries, raw data, figures, README`
4. Click **Commit changes**.

## 3. Add your CSV files
1. Click into the `data/raw` folder.
2. Click **Add file**, then **Upload files**.
3. Drag the 14 CSV files you already have.
4. Commit again with the message `Add raw CSV exports from BigQuery`.

## 4. Send the link
Copy the address from the browser. It looks like:
`https://github.com/YOUR-USERNAME/data5500-school-threat-trends`

That link goes in Progress Report 1.

## Note on file size
GitHub warns above 50 MB per file and blocks above 100 MB. The largest CSV is about 2.7 MB,
so there is no problem.
